# Netflix Movies — Exploratory Data Analysis

## About the project

This project explores Netflix movies released during the 1990s using Python.

The analysis focuses on movie duration, genres, and the number of movies released each year.

## Questions explored

- What was the most frequent movie duration in the 1990s?
- How many short action movies were released?
- How does average movie duration vary by genre?
- How many movies were released in each year of the 1990s?

## Tools and skills

- Python
- pandas
- NumPy
- Matplotlib
- Data filtering
- Grouping and aggregation
- Exploratory data analysis
- Data visualization

## Dataset

The analysis uses the `netflix_data.csv` dataset provided by DataCamp.
The dataset is not included in this repository.

## Project structure

- `netflix_movies_eda.ipynb` — analysis and visualizations
- `netflix_data.csv` — dataset
